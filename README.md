# My Awesome Portfolio

1. Create your project

Generate your portfolio and test it locally.

2. Create a GitHub repository

Create a new repository:

my-portfolio

Then open the terminal inside your portfolio folder and run:

git init

git add .

git commit -m "Create personal portfolio"

git branch -M main

git remote add origin https://github.com/YOUR_USERNAME/my-portfolio.git

git push -u origin main

Replace YOUR_USERNAME with your GitHub username.

3. Open Vercel

Go to Vercel⁠�

Then:

Add New → Project → Import your GitHub repository

Select:

my-portfolio

4. Configure

Use these settings:

Framework: Auto Detect

Root Directory: ./

Build Command: Default

Output Directory: Default

Don't change the settings unless your project requires it.

5. Deploy

Click:

Deploy

Vercel will build your project and provide your live website URL.

6. Test

Open your live website and check:

✅ Homepage

✅ Projects

✅ GitHub links

✅ LinkedIn link

✅ Kaggle link

✅ Resume

✅ Mobile view

✅ Buttons

✅ Navigation
